DocSite Search Helper 使用帮助

DocSite Search Helper 是一个专为文档站点编辑人员设计的浏览器扩展，提供多种实用功能，帮助您更高效地编辑和检查文档内容。

提示： 本扩展专为 GrapeCity 文档站点设计，仅在 docs.grapecity.com.cn 域名下生效。

功能概览

1. 文档搜索

快速搜索当前产品文档中的内容，支持列表视图和树形视图。

使用方法： 按 Alt+, 打开侧边栏，输入搜索内容并点击"搜索"按钮。

2. 常规检查

自动检查文档中的常见问题，如 Mescius 字样、SPAN 标签、DS 产品字样、Base64 内容等。

使用方法： 在侧边栏中点击"常规检查"按钮。

3. 代码格式化

一键格式化选中的代码块，使代码更加规范和易读。

使用方法： 选中代码后按 Alt+Shift+F。

4. SPAN 标签检查

检查编辑器中是否存在 SPAN 标签，避免 HTML 标签混入 Markdown 内容。

使用方法： 按 Alt+Shift+S 执行检查。

5. 图片上传

自动上传 Markdown 中的图片到服务器，并替换为新的链接。

使用方法： 选中包含图片的 Markdown 文本后按 Alt+Shift+U。

6. 链接提取

快速提取选中文本所在的链接地址，并复制到剪贴板。

使用方法： 选中链接文本后按 Alt+L。

详细功能说明

文档搜索

文档搜索功能允许您在当前产品的所有文档中搜索特定内容。搜索结果支持两种查看方式：

  • 列表视图： 以平铺列表形式展示所有匹配的文档
  • 树形视图： 按照文档结构层次展示匹配结果

点击搜索结果可以直接跳转到对应的文档页面。

常规检查

常规检查功能会自动扫描当前产品的所有文档，检查以下常见问题：

  • Mescius 字样： 检查文档中是否包含 "mescius" 字样
  • SPAN 标签： 检查文档中是否包含 HTML SPAN 标签
  • DS 产品字样： 检查文档中是否包含 DsExcel、DsPdf、DsWord 等产品名称
  • Base64 内容： 检查文档中是否包含 base64 编码内容
  • 转义双星号： 检查文档中是否包含转义的双星号 \*\*

检查完成后，会在侧边栏中显示检查结果，点击结果可以查看详细信息。

代码格式化

代码格式化功能使用 Prettier 库对选中的代码进行格式化，支持多种编程语言。

使用步骤：

  1. 在编辑器中选中需要格式化的代码块
  2. 按下 Alt+Shift+F 快捷键
  3. 代码会自动格式化，并显示格式化完成的通知

SPAN 标签检查

SPAN 标签检查功能可以帮助您检测编辑器中是否存在 HTML SPAN 标签，这些标签通常不应该出现在 Markdown 内容中。

使用步骤：

  1. 在编辑文档时，按下 Alt+Shift+S 快捷键
  2. 扩展会检查当前编辑器中的内容
  3. 如果发现 SPAN 标签，会高亮显示并弹出通知
  4. 如果没有发现问题，会显示"文档内容正常"的通知
注意： SPAN 标签在 Markdown 中通常是不需要的，可能会导致文档渲染异常。如果检测到 SPAN 标签，建议将其移除或替换为适当的 Markdown 语法。

链接提取

链接提取功能可以帮助您快速获取选中文本对应的链接地址：

使用步骤：

  1. 选中链接文本（不需要选择整个链接，只需选中链接的一部分文本）
  2. 按下 Alt+L 快捷键
  3. 链接地址会自动复制到剪贴板，并显示通知

常见问题

扩展无法正常工作？

请确保：

  • 您正在访问 docs.grapecity.com.cn 域名下的页面
  • 浏览器已允许扩展在该网站上运行
  • 尝试刷新页面后再使用扩展功能

快捷键不起作用？

可能的原因：

  • 快捷键与其他扩展或系统快捷键冲突
  • 当前页面捕获了快捷键事件

解决方法：您可以在浏览器的扩展管理页面中自定义快捷键。
