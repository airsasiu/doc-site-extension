Documentation Helper 配置

把源站、链接规则和团队检查规则放在同一处管理。调整后会直接影响侧边栏里的搜索、复制和检查流程。

General

界面语言

UI

选择扩展界面显示语言。切换后会立即更新当前页面文案。

这个选择会保存在配置中，并影响扩展的主要界面文案。

Document Copy

文档复制配置

Source

配置从哪个文档站点获取 Markdown 内容，以及是否自动复制到剪贴板。

要获取文档的基础 URL，可填写任意可访问的源文档站地址。
用于获取 TOC 结构；不填时默认使用当前页面所属文档集。
留空时会根据当前 DocSite 页面的域名自动使用 /documentsite/api。
是否将获取的 Markdown 内容复制到剪贴板。

Link Rules

链接处理规则配置

Routing

配置不同文档集的 API 链接和跨站链接转换规则，方便通用化到不同域名的 DocSite。

按文档类型配置路径匹配和替换规则，找不到匹配类型时使用 default。
将外部文档链接映射到当前文档站版本，再继续尝试转换为站内链接。

Checks

常规检查规则

Policy

内置检查会覆盖 SPAN 标签、Base64、转义双星号和绝对链接；这里可以补充团队自己的关键词或正则。

支持 keywords 或 pattern；设置 enabled:false 可临时禁用某条规则。
